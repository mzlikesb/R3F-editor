# 회고

PR이 머지될 때마다 한 줄을 남긴다. 열림→머지 시간은 `gh pr view N --json createdAt,mergedAt`에서 계산한다. 하네스가 실제로 무엇을 잡았고 무엇을 놓쳤는지, 사람을 얼마나 기다리게 했는지를 본다.

| 날짜 | PR | 열림→머지(분) | 잡은 것(누가) | 놓친 것 | 사람 대기 시간 | 규칙화 여부 |
|---|---|---|---|---|---|---|
| 2026-11-26 | #1 하네스 코어 | 149 | 본인 Approve 불가(neon·Codex 1턴) · `GITHUB_TOKEN` 라벨 제거가 이벤트를 안 일으킴(neon 2턴) · 건너뛴 필수 체크가 통과로 처리됨(neon 2턴) · 등급 전환 시 auto-merge 예약 잔존(Codex 2턴) · `r3f-perf` 의존 충돌(QA) · worktree push 시 neon 미실행, 게시 실패 시 재시도 안 됨, 조회 페이지 누락, 빈 판정 리뷰 누락(Codex 코드 리뷰) | `enforce_admins` 꺼짐 — 관리자 머지·main 직접 push로 필수 체크 우회 가능(머지 전 페이블 실측) · 라벨 승인이 변수·GraphQL로 우회됨(페이블) · merge commit 허용 | 플랜 리뷰 3턴 + 코드 리뷰 6회. 사람 관문 4개(플랜 승인, 리뷰 끝, 승인 라벨, 머지) | 훅 오탐 3회(라벨 언급, 커밋 메시지 속 `-uf`, heredoc 속 문자열) → **규칙화 제안**: 훅은 명령 문장 전체가 아니라 해석한 명령 구간만 검사한다 |

| 2026-11-26 | #4 승인 신원 분리 | 50 | 머지 순서 모순·"우회 불가" 과장·자격 증명 충돌·예약 감지 누락(neon 1턴) · `~` 경로 미확장(Codex·neon 2턴) · 설정 누락 시 사용자 계정으로 조용히 넘어감(neon 3턴) · 머지 검사·쓰기 판정 미탐(QA) · 상속 토큰 우회, `-R` 앞 플래그, 구간별 폴더(Codex 코드 리뷰) | neon 리뷰 본문의 `@codex`가 Codex를 실제로 호출함(실행 중 발견) · 워커 계정 Codex 미연결(실행 중 발견) · 사용자가 브라우저에서 워커로 로그인돼 Approve 못 함 | 플랜 3턴 + QA 2회 + 코드 리뷰 3회. 브랜치 보호 전환을 사용자가 직접 해야 해 머지 직전 대기 | 리뷰 지적 중 드문 경우는 이슈로 뺀다(#6) — 사용자 합의. 같은 훅 오탐(구간 해석)이 다시 나오면 규칙 보강 |
