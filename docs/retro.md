# 회고

PR이 머지될 때마다 한 줄을 남긴다. 열림→머지 시간·리뷰 횟수·CI 실패는 `scripts/pr-stats.sh N`으로 뽑는다(#4 이전 PR은 모든 글이 사용자 계정으로 올라가 사용자·neon 칸이 섞여 있다). 하네스가 실제로 무엇을 잡았고 무엇을 놓쳤는지, 사람을 얼마나 기다리게 했는지를 본다.

같은 스크립트의 두 번째 표는 `stage:*` 라벨 기준 단계별 시간·커밋 수와 사람 대기 시간(플랜 승인, Approve)을 준다. "사람 대기 시간" 칸은 이 숫자로 채운다. 플랜 승인을 채팅으로 하면 GitHub에 기록이 없어 플랜 승인 대기는 근사치(0에 가깝게 나온다)다.
