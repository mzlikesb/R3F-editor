# doc-lint (OUTPOST)

절차·점검 축·보고 형식(P1~P3)은 전역 스킬 `~/.claude/skills/doc-lint/SKILL.md`를 그대로 따른다. 여기에 중복해 적지 않는다. 보고 전용이고 문서를 고치지 않는다.

## 이 저장소의 추가 단계

전역 절차의 실상태 수집 뒤에 `scripts/check-protection.sh`를 실행한다. `AGENTS.md` "승인과 머지" 절의 브랜치 보호·병합 방식 주장을 GitHub 실제 설정과 대조한다.

- exit 0: 일치. 보고하지 않는다
- exit 1: 출력된 차이 줄마다 **P1(오도)** 로 보고한다. 문서가 틀렸는지 설정이 바뀐 것인지는 사용자가 정한다
- exit 2: 에이전트 계정 토큰은 보호 설정을 읽을 수 없다(403). 실패로 보고하지 말고, 사용자에게 `! scripts/check-protection.sh`를 사용자 터미널에서 실행해 달라고 안내한다. 결과는 사용자가 붙여 주는 대로 위 규칙에 따라 보고한다
